Консольное приложение на Dart для анализа успеваемости студентов.

## Запуск
1. Клонировать репозиторий: `git clone <url>`
2. Перейти в папку: `cd lab1_dart`
3. Установить зависимости: `dart pub get`
4. Запустить: `dart run`

## Что изучили
- Базовые типы данных и null safety в Dart.
- Работу с коллекциями (List, Map, Set).
- Написание функций и именованные параметры.
- Управляющие конструкции (if, for, switch).

## Ответы на вопросы
1. **Статическая типизация:** В Dart тип проверяется на этапе компиляции, в Python — во время выполнения. Это позволяет находить ошибки раньше.
2. **String?:** Это nullable-тип. Он может содержать null. Обычный `String` — нет.
3. **final:** Гарантирует, что переменная не будет изменена. В Python это только устная договорённость.
4. **{required String name}:** Это именованный параметр. Вызов `func(name: 'Иван')`. Позиционный `func('Иван')`.
